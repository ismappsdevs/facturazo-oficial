## Sobre FacturaZo

FacturaZo es una aplicación móvil para autónomos y freelancers en España, que permite registrar ingresos y gastos y obtener cálculos orientativos de IVA, IRPF y Modelo 130 de forma totalmente offline.

Disponible en Google Play.
